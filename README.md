# 나의 할 일

광고 없는 개인용 할 일 관리 페이지.

## 파일 구성
- `index.html` — 화면의 뼈대
- `style.css` — 색상·글꼴·배치 (맨 위 `:root` 부분의 색만 바꿔도 분위기가 바뀜)
- `app.js` — 할 일 추가·체크·삭제 같은 동작
- `cloud.js` — 구글 로그인, 인터넷 저장소(Firebase Firestore) 읽기·쓰기
- `firebase-config.js` — Firebase 프로젝트 설정값 (비밀번호 아님)
- `미리보기 시작.bat` — 더블클릭하면 http://localhost:5500 으로 미리보기
- `.claude/serve.ps1` — 미리보기용 작은 웹 서버

## Firestore 보안 규칙
`users/{내 계정}/…` 아래만, 등록한 구글 계정으로 로그인했을 때만 읽고 쓸 수 있게 잠가 둠.
