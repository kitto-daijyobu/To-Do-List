# 나의 할 일

광고 없는 개인용 할 일 관리 페이지.

## 파일 구성
- `index.html` — 화면의 뼈대
- `style.css` — 색상·글꼴·배치 (맨 위 `:root` 부분의 색만 바꿔도 분위기가 바뀜)
- `app.js` — 할 일 추가·체크·삭제 같은 동작
- `.claude/serve.ps1` — 미리보기용 작은 웹 서버 (http://localhost:5500)

## 진행 단계
- [x] 1단계: 기본 할 일 목록
- [ ] 2단계: 날짜 + 달력
- [ ] 3단계: 카테고리
- [ ] 4단계: 인터넷 저장소 + 구글 로그인 + 실시간 연동
- [ ] 5단계: 인터넷에 올리기
- [ ] 6단계: 휴대폰 홈 화면 아이콘
- [ ] 7단계: 추가 기능 (미루기, 반복, 플래너, 프로필 등)
